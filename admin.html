📲 Instalar AXONTECH

    

      Navegador detectado: —
    


    
    

      
✅ Tu navegador soporta instalación directa

      
    
        
  1. Pulsa el botón "Instalar ahora" abajo.
    2. 
        
  2. Confirma el aviso que aparece en pantalla.
    3. 
        
  3. Aparecerá un icono de AXONTECH en tu pantalla de inicio. ¡Listo!
    4. 
      

      
También puedes usar el menú ⋮ del navegador → Instalar app.

    


    
    

      
⚠️ Tu Chrome no mostró el aviso automático

      
A veces Chrome no ofrece instalar la app aunque el sitio sea una PWA válida (puede pasar por Chrome muy antiguo, modo escritorio activado, o almacenamiento lleno). Usa cualquiera de estos métodos alternativos:


      
Método 1 — Compartir para agregar a inicio (más rápido):

      
    
        
  1. Pulsa "📤 Compartir / Agregar a inicio" abajo.
    2. 
        
  2. En la hoja de compartir que se abre, busca y elige "Añadir a pantalla de inicio" (en Samsung, Xiaomi y Pixel suele aparecer como destino de compartir).
    3. 
        
  3. Confirma. Aparecerá el icono de AXONTECH en tu pantalla de inicio.
    4. 
      


      
Método 2 — Escanear QR desde otro móvil:

      
    
        
  1. Pulsa "🖼️ Ver código QR" abajo.
    2. 
        
  2. Abre la cámara de otro teléfono que sí tenga Chrome actualizado.
    3. 
        
  3. Apunta la cámara al código QR que aparece en pantalla.
    4. 
        
  4. En ese móvil sí saldrá el aviso automático de instalación.
    5. 
      


      
Método 3 — Copiar URL y enviarla:

      
    
        
  1. Pulsa "📋 Copiar URL" abajo.
    2. 
        
  2. Pégala en un chat de WhatsApp o Telegram.
    3. 
        
  3. Ábrela desde otro teléfono con Chrome actualizado.
    4. 
      


      
💡 Si nada de esto funciona, actualiza Chrome desde la Play Store o instala Chrome Beta. En Chrome moderno (90+) la opción "Instalar app" debería aparecer en el menú ⋮.

    


    
    

      
📱 Samsung Internet

      
    
        
  1. Toca el menú ☰ (arriba a la derecha o abajo).
    2. 
        
  2. Elige "Añadir a pantalla de inicio" o "Instalar app".
    3. 
        
  3. Confirma. Aparecerá el icono en tu pantalla de inicio.
    4. 
      

      
💡 Samsung Internet soporta instalación de apps web en versiones recientes. Si no ves la opción, actualiza el navegador desde Galaxy Store o Play Store.

    


    
    

      
🌐 Opera / Brave / Vivaldi

    2. 
        
  2. Busca "Añadir a pantalla de inicio" o "Instalar app".
    3. 
        
  3. Confirma. Aparecerá el icono de AXONTECH en tu pantalla de inicio.
    4. 
      

      
💡 Estos navegadores están basados en Chromium, así que la opción debería estar disponible en versiones recientes.

    


    
    

      
🥝 Kiwi Browser

      
    
        
  1. Toca el menú ⋮ arriba a la derecha.
    2. 
        
  2. Elige "Añadir a pantalla de inicio" o "Instalar app".
    3. 
        
  3. Confirma. Aparecerá el icono en tu pantalla de inicio.
    4. 
      

      
💡 Kiwi está basado en Chromium y soporta instalación de apps web en versiones recientes.

    


    
    

      
⚠️ Navegador Mi de Xiaomi

      
El navegador que viene preinstalado en tu Xiaomi no permite instalar apps web con un solo botón. Tienes dos opciones:

      
Opción A — Instalar manualmente en Mi Browser:

      
    
        
  1. Toca el icono de menú ⋮ arriba a la derecha.
    2. 
        
  2. Elige "Añadir a pantalla de inicio" (o "Añadir a inicio").
    3. 
        
  3. Confirma. Aparecerá un icono en tu pantalla de inicio.
    4. 
      

      
Opción B — Usar Chrome (recomendado):

      
    
        
  1. Abre la Play Store e instala Chrome (gratis).
    2. 
        
  2. Abre Chrome y entra a AXONTECH.
    3. 
        
  3. Te saldrá un aviso automático para instalar con un toque.
    4. 
      

      
La opción B da mejor experiencia: aviso automático, notificaciones push y actualizaciones sin tener que re-abrir el navegador.

    


    
    

      
⚠️ Navegador Huawei

      
El navegador Huawei no soporta instalación directa con un botón.

      
Opción A — Manual:

      
    
        
  1. Toca el menú ⋮ arriba a la derecha.
    2. 
        
  2. Elige "Añadir a pantalla de inicio".
    3. 
        
  3. Confirma. Aparecerá el icono en tu pantalla de inicio.
    4. 
      

      
Opción B — AppGallery + Chrome:

      
    
        
  1. En AppGallery busca e instala Chrome.
    2. 
        
  2. Abre Chrome y entra a AXONTECH — te saldrá aviso automático.
    3. 
      

    


    
    

      
📱 iPhone / iPad (Safari)

      
    
        
  1. Toca el icono Compartir 􀈂 (cuadro con flecha hacia arriba, abajo en Safari).
    2. 
        
  2. Desplázate y elige "Añadir a pantalla de inicio".
    3. 
        
  3. Pulsa "Añadir". Aparecerá el icono de AXONTECH en tu pantalla de inicio.
    4. 
      

      
Si usas Chrome en iPhone, el proceso es el mismo: menú ⋮ → "Añadir a pantalla de inicio".

    


    
    

      
🦊 Firefox

    4. 
      

      
💡 Firefox aún no soporta el aviso automático de instalación. Para mejor experiencia te recomendamos Chrome, Edge o Samsung Internet.

    


    
    

      
🌐 Tu navegador en Android

      
    
        
  1. Abre el menú del navegador (suele ser un icono ⋮ o ☰).
    2. 
        
  2. Busca la opción "Añadir a pantalla de inicio" o "Instalar app".
    3. 
        
  3. Confirma. Aparecerá el icono de AXONTECH en tu pantalla de inicio.
    4. 
      

      
💡 Para mejor experiencia te recomendamos Chrome, Edge o Samsung Internet, que soportan instalación con un solo toque.

    


    
    

      
💻 Navegador de escritorio

      
Para instalar AXONTECH en tu computadora:

      
    
        
  1. Chrome / Edge: menú ⋮ → "Instalar AXONTECH…" o busca el icono ⊕ en la barra de direcciones.
    2. 
        
  2. Brave: menú ⋮ → "Instalar AXONTECH…".
    3. 
        
  3. Firefox: todavía no soporta instalación de PWAs en desktop.
    4. 
      

      
💡 Para usar AXONTECH cómodamente en el móvil, abre este enlace desde tu teléfono.

    


    
    

      
🔒 Estás dentro de otra app

      
Estás viendo AXONTECH dentro del navegador de Facebook, Instagram o WhatsApp. Para instalarlo necesitas abrirlo en un navegador real:

      
    
        
  1. Toca el menú ⋮ arriba a la derecha.
    2. 
        
  2. Elige "Abrir en Chrome" o "Abrir en navegador".
    3. 
        
  3. Una vez en Chrome, verás el aviso automático "Instalar app".
    4. 
      

      
💡 También puedes copiar la URL y pegarla directamente en Chrome.
